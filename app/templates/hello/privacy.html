プライバシーポリシー

本サービス（以下「当サービス」）は、Meta社のAPI（Instagram Graph API / Threads API 等）を利用し、運用者が承認した範囲でデータを取得・処理します。

1. 取得する情報

  • アカウント識別子（ページID / InstagramビジネスID 等）
  • アクセストークン（運用者が同意した範囲）
  • Webhook経由のイベント（メッセージ、メンション等）
  • 当サイトの操作ログ（監査目的）

2. 利用目的

  • SNS運用・返信・分析等の機能提供
  • 障害対応・不正利用防止・品質改善
  • 法令・利用規約の遵守

3. 第三者提供

法令に基づく場合を除き、本人の同意なく第三者に提供しません。

4. 保管期間と管理

当サービスは、取得した情報を利用目的の達成に必要な期間に限り保管します。
Instagram Direct メッセージの本文、送信者・受信者のアカウント識別子（Instagram ユーザーID / PSID）、タイムスタンプ、Webhook イベントログ、API レスポンスは、取得から最大12か月間保管し、経過後は削除または匿名化します。
アクセストークンは、連携解除または失効の時点で速やかに削除します。
操作ログは監査目的で最大12か月間保管します。
保管にあたっては、アクセス権限管理および暗号化等の安全対策を講じます。

5. 利用者の権利

保有個人データの開示・訂正・削除・利用停止の請求が可能です。連絡先は下記をご参照ください。

6. クッキー等の利用

ログイン維持や分析目的でクッキー等を利用する場合があります。ブラウザ設定で無効化可能です。

7. 改定

必要に応じて本ポリシーを改定します。改定後は本ページで告知します。

8. お問い合わせ

保有個人データの開示・訂正・削除・利用停止のご請求、その他本ポリシーに関するお問い合わせは、下記までご連絡ください。
