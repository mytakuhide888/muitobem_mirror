連携ガイド（Facebook / Instagram / Threads）— はじめてでも迷わない手順書

このガイドは、Meta 連携を初めて設定する方向けに、どこを開き、どの項目に何を入れるかを具体的に説明します。

0. 用語と前提

  • SITE_BASE: あなたの公開URL（例: https://muitobem.top）
  • OAuth戻り先: {{ request.scheme }}://{{ request.get_host }}/oauth/meta/callback/
  • Webhook Verify: {{ request.scheme }}://{{ request.get_host }}/oauth/meta/webhook/
  • Webhook Inbound: {{ request.scheme }}://{{ request.get_host }}/oauth/meta/webhook/inbound/
  • Verify Token: 任意の長い文字列（Meta側と .env を一致）

1. 全体の流れ

  1. Facebook開発者でアプリを作成し、Facebook Login / Instagram Graph API / Webhooks を追加
  2. Facebook Login に 有効なOAuthリダイレクトURI を登録
  3. Webhooks に コールバックURL と 検証トークン を登録（Instagram／必要に応じてPageも）
  4. muitobem サイトの .env を設定して再起動
  5. 管理画面から OAuth 開始 → ページ取り込み → Webhook疎通確認

2. Facebook開発者コンソールの具体手順

  1. マイアプリ → アプリを作成（種類: ビジネス 推奨）
  2. 左メニュー 設定 > ベーシック
    • アプリドメイン にドメインを追加（例: muitobem.top）
    • 必要に応じてプライバシーポリシーURLなども登録
  3. 製品を追加 から Facebook Login / Instagram Graph API / Webhooks を追加
  4. Facebook Login > 設定 → 有効なOAuthリダイレクトURI に {{ request.scheme }}://{{ request.get_host }}/oauth/meta/callback/ を入力 → 保存
  5. Webhooks → サブスクリプションを追加 → オブジェクト=Instagram
    • コールバックURL: {{ request.scheme }}://{{ request.get_host }}/oauth/meta/webhook/
    • 検証トークン: .env の META_WEBHOOK_VERIFY_TOKEN と同じ値
    • 必要な フィールド（例: messages, mentions, comments）を選択
  6. 必要に応じて オブジェクト=Page も同様に登録（Messenger 連携等）

3. サイト側の設定（.env と Django）

SITE_BASE={{ request.scheme }}://{{ request.get_host }}
META_APP_ID=＜FacebookアプリID＞
META_APP_SECRET=＜Facebookアプリシークレット＞
META_WEBHOOK_VERIFY_TOKEN=＜検証トークン＞
# 任意
META_OAUTH_REDIRECT_URI={{ request.scheme }}://{{ request.get_host }}/oauth/meta/callback/

Django 側は ALLOWED_HOSTS・CSRF_TRUSTED_ORIGINS を適切に設定し、必要なら SECURE_PROXY_SSL_HEADER 等も有効化。

4. 実行と確認

  1. ブラウザで /oauth/meta/start/ → 同意 → /oauth/meta/callback/
  2. コールバック画面で 権限(granted/declined) と ページ一覧 を確認 → ページ取り込み
  3. Webhook Verify: 
    curl -i "{{ request.scheme }}://{{ request.get_host }}/oauth/meta/webhook/?hub.mode=subscribe&hub.verify_token=XXXX&hub.challenge=12345"
  4. Webhook Inbound（署名付き）: 
    RAW='{"object":"instagram","entry":[{"id":"<ID>","changes":[{"field":"messages","value":{"sample":"ok"}}]}]}'
SIG=$(printf '%s' "$RAW" | openssl dgst -sha256 -hmac "$META_APP_SECRET" -r | awk '{print $1}')
curl -i "{{ request.scheme }}://{{ request.get_host }}/oauth/meta/webhook/inbound/"   -H "X-Hub-Signature-256: sha256=$SIG"   -H "Content-Type: application/json"   -d "$RAW"

5. よくあるつまずき

  • redirect_uri mismatch: Facebook Login の「有効なOAuthリダイレクトURI」に /oauth/meta/callback/ を入れ忘れ
  • verify_token mismatch: Meta 側の検証トークンと .env が不一致
  • 署名エラー403: X-Hub-Signature-256 の生成に App Secret を使っていない／RAW本文が一致していない
  • Page→IG解決できない: Instagram がプロアカウントでない／Facebookページとリンクしていない

詳細運用は「運用コンソール＞テンプレ編集」「ログ閲覧」等の画面を参照してください。
