言葉は悪いですが、恋愛占いをうける人はメンヘラになっています。
悩んでるというよりもメンタルぐちゃぐちゃという感じです。

同じ職場での片思い、言い合いになって破局、不倫相手が時間を使ってくれない。
こういう悩み相談が強いメンヘラになっている傾向が強いです。

上記ポストの通り、男からしたら超面倒なので避けられている可能性があるなと相談文から分かります。

で、このメンヘラには2パターンあるんです。

①メンヘラに罪悪感ありタイプ
自分がメンヘラ（ヒス、ふてくされる、性格が悪くなってしまう）になってしまうことを悪いと思いつつも、「メンヘラになって病んでるから彼に気遣いをしてもらいたい」と望んでいるタイプです。
自己中に感じるかもしれませんが、IQが下がってるから仕方ない部分もあります。自分も少しは悪いとは思ってはいます。

自分がメンヘラになることで「しんどい」「辛い」「彼から嫌われる」と自覚ができているタイプではあります。

➁自己中ワガママタイプ
もう一方は、超自己中心的でワガママなタイプ。
そもそもメンヘラになる前から性格に難ありで、周りに友達も少ない。
もはや恋愛でメンヘラになっているというよりも、欲望を叶えられずにイライラしている状態の時もある。スピで言うところのエネルギーバンパイア。

とにかく「何がなんでも自分を最優先にして彼が動いてくれる」ことを望んでいます。彼が考えることすら自分中心であってほしい。相手を支配したいタイプになります。

メンヘラになって辛いというよりも、自分に都合よく彼が動いてくれない（愛してくれない）ことに憎しみさえ抱いてることもあります。

補足ですが、どちらのタイプのお客さんにも共通しているのは、恋愛において「自分が我慢している」「自分の意志を殺している」と感じているということです。

相談文にはっきりそう書かれていなくても、心の奥では多くの人がそう思っています。

「恋愛がうまくいかない」「彼に好かれない」「復縁できない」という現実に直面したとき、「私は我慢してるのに報われない」という自己認識を作って相談してきます。

恋愛をしてアホになってしまい、衝動的に彼に手紙を渡して撃沈しただけのケースでも、「私は気持ちを押し殺してる」と主張してしまうような、矛盾した人もいます。

要は「自分が我慢している」という物語をつくらないと、プライドが傷つきすぎて耐えられないからです。

彼に自分の気持ちを分かってもらいたい。

メンヘラ（クソな自分）も含めて好きになってもらいたい。

思い切って気持ちを伝えても好意が返ってこない。

相談文に上記のようなことが書いてあると「この人は自分が我慢しているつもりなんだな」と裏の気持ちを推測できるようになります。

そこに寄り添って「あなたは気持ちを抑え込んでいますね」と言葉を添えると、ちゃんと相談文を読んでくれて理解してくれてる占い師だと思ってもらえます。アップセルにも繋がります。

更に補足で、占い歴が短い人向けに「絶対に守らないといけない鉄則」を伝えておきます。

まず大前提として、お客さんは何も悪くないという前提で話を進めなければいけません。

「あなたが悪いから恋愛がうまくいかないんです」と突きつけてしまったら、一瞬で心を閉ざされますし、セールスどころか低評価やクレームにつながります。

占い師はお客さんの味方である、というポジションを崩してはいけないんです。

そのうえで、①のタイプ、自分がメンヘラになっている自覚があり、そのせいで恋愛がうまくいっていない、苦しい。と感じているお客さんには、波動修正やヒーリングの提案がおすすめです。

お客さん自身を癒してあげる提案をします。

「あなた自身が苦しんでいる波動を調整していきましょう」
「乱れたエネルギーを整えることで、自然と関係性も改善していきます」
と伝えることで、責めることなくスピってる解決の道を示せる。

もし、本当に効果を感じさせるヒーリングが出来るなら、リピーターさんにもなってくれます。

相談文でメンヘラになって揉めたエピソードや、自分がメンヘラになった直近の出来事を相談文に書いている人が対象になります。

メンヘラになってしまい、どうしていいか分からないから相談に来ているわけです。
普段の性格も悪くないので長期の高額講座が売れるのは、こういうタイプです。

要は、お客さんを否定せず、寄り添いながらもメンヘラによる悪循環を断ち切るサポートを提示すること。

メンヘラが改善されると、稀に彼と付き合えたり復縁できたりも出来るので、お客さんにも感謝されます。

では、タイプ➁のぶっとんだ自己中メンヘラタイプ。

このタイプに関しては、絶対に「あなたに問題があります」と言ってはいけません。
スピっている内容であってもダメです。

どこまでも「彼に問題がある」「彼が理解できていない」「彼が変わるべき」という流れに持っていくことが鉄則です。
（彼が悪いケースもありますが、それはさておき相談者を全肯定するのが重要。）

お客さんが望んでいるのは、「彼が自分の都合のいいように変わること」
だからこちらの提案も、「彼が変わる。彼が動く」方向にしていく必要があります。

ヒーリングや波動修正をする場合も、彼に対して行うスタンスを取る。

一番良いのは「思念伝達」 です。
「あなたの気持ちを彼に届けて、その気持ちに応えるように彼が動いてくれる」
「あなたの愛にこたえるように最優先に考えてくれる」
このような施術の提案が、自己中タイプにはハマります。
求められています。

もし、思念伝達や対彼アプローチに抵抗を感じるなら、物販がおすすめです。
大友はこのタイプのお客さんに対しては、5万〜10万の商品をずっと提供してきました。

「持っているだけで彼から愛される」「波動が共鳴して彼が貴方のために動いてくれる」
このような物販は、自己中タイプにとって理想なんです。

絶対に避けるべき提案は、長期講座です。
このタイプのお客さんは「自分が変わる」ことを望んでいないから。
メンヘラのまま、自己中なまま、愛されたい。
だから「自分を変えましょう」という長期的な内容には反発しかしません。

短期的欲求で彼に変わってもらいたいんです。

もちろん現実的には、男からすればメンヘラが一番嫌いで、自己中な女が愛されることはまずありません。

でも、副業占いの世界では「お客さんが望んでいることを提供する」のが鉄則。

現実的な正論ではなく、お客さんが求める願望を肯定してあげることが、高単価アップセルに繋がります。

見極めのポイントとしては、相談文を読んだときに、自分のことを書かずに「彼の愚痴や悪口ばかり」を並べている場合。
このパターンは高確率でタイプ②です。

「彼に変わってもらいたい」「彼が悪いから苦しい」という視点で書かれている時点で、自己中でワガママな欲求が透けて見えます。

他責にして自分が我慢しているという被害者意識の方が傷つかなくていいので、自然とそういう思考になっているんです。

最後になりますが、好きな人と接点がない、そもそも会うことが少なかったり出来ないことでメンヘラになってる人には「縁結び」を提供するのも良いアプローチです。

相談文に自分のことが中心で書いてあるのか、それとも相手中心で書いてあるかを見極めて、違うアップセルの提案をしたほうが成約率と高単価率も上がってきます。
全て同じ提案では、お客さんには響かないです。
