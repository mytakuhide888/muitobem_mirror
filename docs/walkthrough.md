## 改善の具体的内容

### バズ投稿取得時のプロフィール取得

**Before:** `followers_count` が未設定の場合のみプロフィール取得 → 初回以降はプロフィール未更新

**After:** 同一実行内で未取得のアカウントは**全て**プロフィールを取得 → bio、フォロワー数、バッジ等が常に最新

### 深堀スキャンの対象条件拡大

**Before:** フォロワー数が既知のアカウントのみ対象 → フォロワー不明アカウントが対象外で永遠に情報不足

**After:** 
1. フォロワー未取得アカウント（**最優先**）
2. フォロワー既知＋投稿不足（3件以下 or NULL）

max-authors デフォルトも **10 → 30** に増加
