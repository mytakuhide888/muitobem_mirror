# muitobem 運用方針提案書（v1）

## 1. プロジェクト目的（再整理）

**一言**: 占い×AI×SNSで、複数キャラクターを同時運用し、自動化で効率的に収益を上げるプラットフォーム

### ビジネスの流れ
```
[集客] Threads/Instagram で占い師キャラが毎日投稿
  ↓
[無料体験] コメント/DM → 自動応答で無料鑑定を提供
  ↓
[信頼構築] ヒアリング（生年月日、悩み）→ AI鑑定文を返送
  ↓
[有料転換] 無料鑑定に満足 → STORES等で有料鑑定を購入（成約率10-20%目標）
  ↓
[リピート] フォローアップDM / イベントローンチ / 物販（パワーストーン等）
```

### 収益目標の目安（参考アカウントより）
| フェーズ | 目安期間 | 月収目安 |
|---------|---------|---------|
| 0→1達成 | 1-3ヶ月 | 1-5万円 |
| 安定期 | 3-6ヶ月 | 10-30万円 |
| 成長期 | 6-12ヶ月 | 30-100万円 |
| 横展開 | 1年以降 | 100万円+ |

## 2. コンセプト設計の方針

### 2.1 ニッチ選定の考え方

参考アカウント（メイト氏、澪氏）の共通見解:
- **「競合が弱い市場」を狙う** のが鉄則（澪氏）
- **検索ボリュームがあるのに供給が少ない** 組み合わせを探す
- **大手が避ける領域** ＝ 個人が勝てる領域

### 2.2 有力なジャンル候補

市場調査・参考アカウント分析から:

| ジャンル | 需要 | 競合 | 推奨度 | 備考 |
|---------|------|------|--------|------|
| **恋愛（片思い・復縁）** | 極大 | 多い | ★★★ | 最大市場。差別化が鍵 |
| **ツインレイ・ソウルメイト** | 大 | 中程度 | ★★★★ | スピ層の熱量が高い。高単価が通る |
| **金運・開運** | 大 | 多い | ★★★ | 物販（パワーストーン等）と相性良好 |
| **仕事運・転職** | 中 | 少ない | ★★★★ | ニッチ。30代以上のキャリア層に刺さる |
| **毒親・家族関係** | 中 | 少ない | ★★★★★ | 悩みが深い。リピート率高。競合弱い |
| **自己肯定感・メンタルヘルス** | 大 | 中程度 | ★★★★ | カウンセリング要素。単価上げやすい |

### 2.3 推奨コンセプトパターン

**パターンA: 恋愛×タロット特化型（王道）**
- ターゲット: 20-40代女性、片思い・復縁・不倫に悩む層
- 占術: タロット（ビジュアル映えする）
- 強み: 市場最大。リール3択タロットが鉄板（コメント→自動DM）
- 弱み: 競合多い。差別化にキャラ設計の工夫が必要

**パターンB: 金運×スピ物販型（収益重視）**
- ターゲット: 30-50代、金銭的な悩みを持つ層
- 占術: 四柱推命 + パワーストーン提案
- 強み: 物販と連動。LTVが高い（パワーストーン8,000-20,000円）
- 弱み: 物販の在庫・発送管理が必要

**パターンC: ツインレイ×ヒーリング型（高単価）**
- ターゲット: 30-50代女性、スピリチュアルに関心の高い層
- 占術: 霊感 + エネルギーワーク + タロット
- 強み: 客単価が高い（月額49,800円サポートも成立）。熱量の高いファン
- 弱み: ニッチすぎると母数が限られる

**パターンD: メンタルケア×四柱推命型（ニッチ）**
- ターゲット: 30-40代女性、自己肯定感低め、人間関係で悩む層
- 占術: 四柱推命（生年月日ベースでAI生成しやすい）
- 強み: カウンセリング要素で差別化。寄り添い型で信頼構築しやすい
- 弱み: スピ感が薄いと訴求力が弱い

### 2.4 コンセプト設計時に決めるべき項目

| 項目 | 内容 | 例 |
|------|------|-----|
| キャラクター名 | 占い師としての名前 | 「月詠ルナ」「紫苑 凛」等 |
| 肩書き | 一言で何者か | 「ツインレイ専門タロティスト」 |
| アイコン | 目を引くビジュアル | AIイラスト生成（幻想的・神秘的） |
| ターゲット | 誰に向けて | 「30代 片思いに悩む女性」 |
| 悩みの深さ | どんな痛みを解決 | 「あの人の本音が知りたい」 |
| 占術 | 使う占い手法 | タロット / 四柱推命 / 数秘術 |
| 文体 | 話し方のトーン | 優しいお姉さん / 厳しめ姉貴 / 神秘的 |
| 無料→有料の導線 | 転換の仕組み | リールコメント→DM→無料鑑定→有料案内 |
| 価格設定 | 有料鑑定の価格帯 | 3,000円 / 5,000円 / 10,000円 |

### 3.2 Claude API 統合方針

**用途**:
1. **鑑定文生成**: タロット/四柱推命の結果をベースに、キャラクターの文体で鑑定文を出力
2. **投稿文生成**: 集客用のThreads/Instagram投稿文をキャラの文体で生成
3. **DM応答文生成**: 顧客のDMに対する返信文をキャラの文体で生成
4. **NGワードチェック**: 生成した文章の法令違反チェック

**実装イメージ**:
```python
# 鑑定文生成の基本フロー
class DivinationService:
    def generate_reading(self, account, customer_info, divination_type):
        """
        account: キャラクター設定（文体、名前等）
        customer_info: 生年月日、悩み、性別等
        divination_type: タロット / 四柱推命 / 数秘術
        """
        # 1. プロンプトテンプレート取得
        prompt = self.get_prompt_template(divination_type)

        # 2. キャラクター設定を注入
        prompt = self.inject_character(prompt, account)

        # 3. 顧客情報を注入
        prompt = self.inject_customer_info(prompt, customer_info)

        # 4. Claude API呼び出し
        result = claude_api.generate(prompt)

        # 5. NGワードチェック
        result = self.check_ng_words(result)

        # 6. PDF生成（必要に応じて）
        pdf = self.generate_pdf(result, account)

        return result, pdf
```

## 4. 禁止事項・法令遵守

### 4.1 自動チェック対象

| カテゴリ | NGキーワード例 | 対応 |
|---------|-------------|------|
| 霊感商法 | 「受けないと不幸」「呪い」「除霊しないと」 | 生成時にブロック |
| 確実性 | 「必ず叶う」「100%当たる」「絶対」 | 警告表示 |
| 医療法・薬機法 | 「病気が治る」「薬をやめて」「癌に効く」 | 生成時にブロック |
| 著作権 | 他アカウントの文章の丸コピー | 類似度チェック |
| プラットフォーム規約 | スパム的な連続投稿、禁止ワード | 投稿前チェック |

### 4.2 人間レビューが必要な場面
- 新しいキャラクター/コンセプトの立ち上げ時
- 高額商品（1万円以上）の案内文
- クレーム/返金対応
- 法的にグレーな表現のレビュー

## 5. 推奨する着手順序

### Step 1: コンセプト設計（人間の意思決定）
- キャラクター、ターゲット、占術、文体、価格帯を決定
- Googleトレンドやバズ検索で市場性を確認
- 本プロジェクトのバズ検索機能を活用して競合分析

### Step 2: AI鑑定文のプロトタイプ（システム）
- Claude API連携の基盤実装
- プロンプトテンプレートの作成・調整
- テスト鑑定文の品質確認（人間レビュー）

### Step 3: コンテンツ準備（人間+システム）
- 無料鑑定用の定型プロンプト確定
- 有料鑑定のプロンプト確定（より詳細・高品質）
- STORES等に有料商品を配置

### Step 4: アカウント開設・集客開始（人間+システム）
- Threads/Instagramアカウント開設
- AI投稿文生成 → 毎日投稿開始
- バズアカウントリサーチの継続実施

### Step 5: 無料鑑定→有料鑑定の導線構築（システム）
- DM自動応答の実装
- ヒアリング→鑑定文生成→送信の自動化
- 有料鑑定への案内テンプレート
