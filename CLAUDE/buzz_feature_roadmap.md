# バズアカウントリサーチ機能 — 全体方針・修正経緯・今後のロードマップ

最終更新: 2026-02-14

---

## 1. プロジェクトの最終目的

**Threads/Instagram上で占いコンテンツを提供し、マネタイズする。**

具体的には:
1. よく売れている占いアカウントを見つけて分析し、コンセプト設計の参考にする
2. 参考アカウントの成功要因を「少しずらして」独自の魅力的なキャラクターを作る
3. そのキャラクターでThreads/Instagramに毎日投稿し、集客する
4. 無料占い → 有料占い → リピート・物販（パワーストーン等）の導線で収益化する

### ビジネスフロー
```
[リサーチ]  バズアカウントを検索・急成長ランキングで分析
     ↓
[コンセプト設計]  伸びている要因を3つ以上ピックアップ → 少しずらして差別化
     ↓
[集客]  Threads/Instagramで毎日投稿（AI生成、タイマー自動投稿）
     ↓
[無料体験]  コメント/DM → 自動応答で無料鑑定を提供
     ↓
[信頼構築]  ヒアリング（生年月日・悩み）→ AI鑑定文を返送
     ↓
[有料転換]  STORES等で有料鑑定を購入（成約率10-20%目標）
     ↓
[リピート]  フォローアップDM / イベントローンチ / 物販
```

### 収益目標の目安
| フェーズ | 目安期間 | 月収目安 |
|---------|---------|---------|
| 0→1達成 | 1-3ヶ月 | 1-5万円 |
| 安定期 | 3-6ヶ月 | 10-30万円 |
| 成長期 | 6-12ヶ月 | 30-100万円 |
| 横展開（複数アカウント） | 1年以降 | 100万円+ |

## 2. コンセプト設計の方法論

メイト氏（インスタマーケ道場創業者・累計8桁売上）のコンセプト設計指南書に基づく。

### 3ステップ

**Step 1: 直近で異常に伸びているアカウントを見つける**
- 「最近作られたアカウントなのにめっちゃ伸びている」 = 今、需要がある証拠
- 目安: 初投稿で10万imp / 開設1週間でフォロワー3,000人 / 開設1ヶ月でフォロワー10,000人
- 見つからない場合はハードルを下げる（5万imp / 1,000人 / 5,000人）
- **本ツールでの操作**: 急成長ランキング画面で「アカウント日数(若い順)」ソート、「最大日数90日」「最小フォロワー500」で絞り込み

**Step 2: 伸びている要因を3つ以上ピックアップする**
- チェックポイント: プロフィール（表示名、bio）、コンセプト（何者か、ギャップ）、投稿内容（バズ投稿の傾向）、投稿形式（テキスト/画像/動画）、経歴、投稿頻度
- **本ツールでの操作**: 投稿者詳細画面でピン留め投稿・バズ投稿を分析

**Step 3: ピックアップした要素を少しずらしてコンセプトを固める**
- 伸びている要因は残しつつ差別化する
- 例: 「元博多のキャバ嬢占い師」→ 博多弁がウケている → **関西弁**にずらす
- 丸パクリは禁止。必ず何かしら差別化する
- **核心**: 0からオリジナルで生み出すのではなく、市場に落ちている"答え"から逆算して設計する

### 参考: 成功している占いアカウントの共通点（メイト氏・他の発信より）
- 集客数が最重要（月100万円プレイヤーは全員、大量集客している）
- お客様と「親友」のような関係を築く（LTVがバグる）
- 毎日投稿は当たり前。量が質を生む
- 無料鑑定→有料鑑定の成約率10%以上を目指す。鑑定前後のやり取りが重要
- 購入者にDMでフォローアップ → リピーター獲得
- 複数アカウント運用でリスク分散（ただし1垢で30万以上出てから）

### 3.4 スコアリング指標
| 指標 | 計算式 | 用途 |
|------|--------|------|
| 成長スコア | フォロワー密度 × エンゲージメント品質 × 信頼度 | 急成長アカウント発見 |
| 品質スコア | エンゲージメント品質(40%) + 直近活動度(25%) + 投稿頻度(20%) + 信頼度(15%) | 投稿内容の質評価 |
| ER | (いいね+リプライ+リポスト) ÷ フォロワー数 × 100 | 投稿の反応率 |
| エンゲージメントスコア | いいね×1.0 + リプライ×3.0 + リポスト×2.5 | 投稿単位の反応量 |
| バズ判定 | フォロワー規模別の閾値 | バズ投稿の検出 |

### 3.5 自動判定フラグ
| フラグ | 条件 | 用途 |
|--------|------|------|
| コンセプト候補 | 7-90日 + フォロワー500+ + F/日10+ + スコア算出済 | リサーチ対象の自動絞り込み |
| 優良アカウント | 品質スコア50点以上 | 投稿の質が高いアカウント |
| お気に入り | 手動トグル | ユーザーが選んだ参考アカウント |
| 対象外 | 手動トグル（個別/一括） | 不要なアカウントの除外 |

### Phase 3.5: ランキング画面UI拡張の詳細（2/14 セッション1）

#### 初回実装（全Step完了）
- **モデル**: THBuzzAuthor に `profile_pic_url` URLField(500) 追加 + マイグレーション0013
- **スクレイパー**: `_extract_profile_from_html()` にプロフィール画像URL抽出を追加
- **管理コマンド4本**: `profile_pic_url` 保存ロジックを各コマンドに追加
- **ランキングテンプレート**: カードにチェックボックス、プロフィール画像、お気に入り/対象外ボタン、バッジ表示、一括操作バーを追加
- **JavaScript**: toggleFav, toggleExcl, bulkExclude, updateBulkBar, clearChecks を追加

#### 修正1: プロフ画像未表示 + ボタン位置
- **原因**: スクレイパーが `"profile_pic_url":"..."` のSSR JSON形式しか対応しておらず、HTMLの `<img>` タグフォールバックがなかった
- **対応**: SSR JSON複数キー対応 + `<img>` タグフォールバック追加
- **追加**: ボタンをカード下部 → 上部右寄せに移動
- **追加**: 投稿者詳細画面にもプロフィール画像を表示

#### 修正2: プロフ画像まだ未表示（根本原因）
3件の重大バグを発見・修正:
- **(a) 早期return問題**: `"username":"xxx"` がSSR JSONで見つからない場合に `return` していたため、`<img>` タグフォールバックに到達しなかった → `if match:` ブロック構造に変更
- **(b) chunk範囲不足**: 前2000/後5000文字では profile_pic_url が範囲外になる場合があった → 前3000/後8000文字に拡大
- **(c) JSONオブジェクト形式**: `hd_profile_pic_url_info` は `{"url":"..."}` というオブジェクト型なのに、文字列値として検索していた → オブジェクト形式のパースに修正
- **リファクタ**: `_extract_profile_pic_from_html()` を独立関数に切り出し、SSR JSON成功/失敗に関わらず常に最終フォールバックとして実行

#### 修正3: CDN画像のCORP問題
- **原因**: `cdninstagram.com` のプロフィール画像をブラウザから直接参照 → Cross-Origin Resource Policy でブロック
- **対応**: 既存の `buzz_media_proxy` エンドポイント（投稿画像用に実装済み）を発見・活用。JavaScriptで `cdninstagram.com` URLをプロキシ経由に自動書き換え（ランキング画面・投稿者詳細画面の両方）

#### 修正4: プロフィール画像一括更新コマンド
- **新規作成**: `th_buzz_update_avatars` コマンド — `profile_pic_url` が空のアカウントを一括取得・更新
- `--max-authors 50` で件数制限、`--all` で既取得分も再取得可能
- プロフ画像だけでなく display_name, bio, followers_count 等も同時更新

#### 修正5: バッジ・ボタンの重なり問題
- **原因**: 認証済/候補/優良/対象外/お気に入りのバッジとアカウント名が `<h3>` 内の同一行にあり、長い名前で重なる
- **対応**: バッジとボタンをアカウント名の上に独立した行 `.gr-card-top-row` として分離。ランク番号 + バッジ群 + アクションボタンがflex-wrapで折り返し表示。`<h3>` はアカウント名のみに簡素化

## 7. 推奨する着手順序

現在はPhase Aのリサーチ機能がほぼ完成しており、実際にリサーチ運用が始まっている段階。

### 直近（1-2週間）
1. **リサーチ運用の本格開始** — 現在の機能を使ってキーワード巡回・深掘りスキャン・候補分析を毎日実施

## 8. 参考: 占いアカウント成功の鍵（先行者の知見）

メイト氏（累計8桁売上）やスピ童貞氏、あおい氏（月285万）等の発信から抽出した知見:

### 集客
- **SNSが毎日更新されている = 儲かっている可能性が高い**。必ず導線をチェック
- 月100万円プレイヤーの共通点: **集客数が大量**。鑑定力は後からなんとでもなる
- 「競合がいない、でも確実に需要がある」ポイントを狙い撃ち
- 占いだけでなく**隣接ジャンル**（カウンセリング、スピ、ヒーリング）もリサーチする

### マネタイズ
- **無料鑑定→有料鑑定の成約率10%以上**が目安
- 鑑定文そのものの強化だけでなく、**鑑定前後のやり取り**が超重要（例: 鑑定書の読み方を先に伝える）
- 無料鑑定の結果が出るまで**5通くらいやり取り**すれば成約率20-30%超え
- **購入者にDMを片っ端から送る**。営業心を忘れない
- パワーストーン（8,000-20,000円）は鑑定後の提案で売れる

### リピート
- **お客様と親友のような関係**を築く = LTVがバグる
- リピート購入だけで月50万超え: (1) 全返信を丁寧に (2) 有料商品の満足度を極限まで (3) 定期的に営業（ストーリー・個別DM・一斉配信）
- LINEリスト40人でも月30万円 — **太客×高リピート**

### コンセプト
- 占い師だからと言って演じる必要はない。素を出してOK。人間味がウケる
- **コピーライティング**と**プロンプト構築**は必須スキル
- 「何かあったときにすぐ相談に乗って欲しい先生」というポジションを脳内で取れた瞬間、売上が安定する
